# 画板插件（sketch:pad）

> 本插件是本仓库**手写新增**的，不属于上游 Infinite Canvas（原版无此节点）。

## 1. 它解决什么问题

本地出图最容易卡住的一环是**"我没法把想法准确地描述成提示词"**。
画板让你**用手画**——画个构图、勾个姿势、描一张参考图——直接把结果当参考图喂给生成卡，绕开"提示词玄学"。

三个典型用法：

| 用法 | 流程 |
|---|---|
| **构图草图** | 画板画火柴人/几何体构图 → 导出图片节点 → 接 Krea2 / Z-Image 出图 |
| **描摹定妆** | 把角色图连到画板当底图（28% 半透明）→ 描出线稿/五官位置 → 导出 → 接 H3 Image 编辑 |
| **手绘蒙版** | 把原图连到画板 → 用橡皮擦出要保留的区域（或反之）→ 导出 → 接 Qwen2.1 局部重绘 |

## 2. 文件位置

```
infinite-canvas/web/dist/plugins/sketch-pad.js     ← 运行时真正加载的（构建产物目录，手写覆盖）
infinite-canvas/web/dist/plugins/index.json        ← 插件清单，必须含 "/plugins/sketch-pad.js"
infinite-canvas/web/public/plugins/…               ← 与 dist 保持一致（源码位备份）
```

> dist 是构建产物，理论上重新 build 会覆盖。**本插件是手写的，不走构建**，所以直接放在 dist 里；升级上游后记得把这两个文件 + index.json 的第四条抄回来。

加载机制：前端启动时 `fetch("/plugins/index.json")` → 逐条动态 `import()` → 插件返回 `{ id, name, nodes: [...] }` 完成节点注册。

## 4. 操作流程

```
双击画布 → 新建节点菜单 → 「画板」
   ↓
双击画板卡片（或工具条 ✏️ 画板）→ 打开全屏画板
   ↓
画 / 描摹 → Enter 完成（或点「完成」）
   ↓
工具条「导出图片」→ 右侧生成一个图片节点「<画板名> 线稿」
   ↓
把图片节点连到 图片卡 / H3 Image 编辑 / Qwen2.1 局部重绘
```

## 5. 画板内功能

| 功能 | 细节 |
|---|---|
| 笔触引擎 | 内联 **perfect-freehand 1.2.3**（MIT, Stephen Ruiz），离线可用，无外网依赖 |
| 压感 | 手写笔用真实 `pressure`；鼠标固定 0.5 |
| 工具 | 画笔 `B` / 橡皮 `E` |
| 粗细 | 2 ~ 48（滑块，标签实时显示） |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`，按钮有禁用态 |
| 清空 | 二次确认；提示「清空后可用重做逐步恢复」 |
| 画布尺寸 | 1024×1024（1:1）／1024×576（16:9）／576×1024（9:16）／768×768（快、省显存） |
| 底图描摹 | 连入图片按 **28%** 透明度铺底（`GUIDE_ALPHA = 0.28`），可勾选开关；跨域失败会提示「底图读取失败（跨域或文件已失效），可继续手绘」 |
| 完成/取消 | `Enter` 完成 / `Esc` 取消 |
| 导出 | 白底合成 PNG，写入节点 metadata（`content`、`sketchWidth`、`sketchHeight`） |
| 持久化 | `ctx.storage` 前缀 `sketch:<nodeId>`，重载画布笔画仍在 |

## 6. 工具条按钮

| 按钮 | 行为 |
|---|---|
| ✏️ **画板** | `onDoubleClick` → 打开全屏画板 |
| **导出图片** | `dispatch({ type:"add_node", nodeType:"image", title:"<画板名> 线稿", x: 原节点右 +60 })` |
| 🗑 **清空** | 删 `sketch:<id>` 存储 + 清 metadata（二次确认） |

## 7. 为什么能直接当下游的参考图

节点实现了 `resource()`：

```js
resource: (node) => {
  const content = node?.metadata?.content;
  return typeof content === "string" && content
    ? { kind: "image", url: content }
    : null;
}
```

画板有内容后会被画布当作**图片资源**，可以直接拉到任何需要图片输入的卡片上。

## 8. 已知限制

| 限制 | 说明 |
|---|---|
| 只有画笔/橡皮 | 没有直线、矩形、文字、图层、参照网格 |
| 无透明度/色彩 | 单色黑笔（白底），因为输出是给模型当**结构参考**，不是成品图 |
| 单张持久化 | 一张画板存一份合成 PNG，不存笔画矢量（撤销历史只在本次会话内） |
| 底图不可缩放/平移 | 当前是 `fit` 铺满画布，不能局部放大描细节 |
| 触屏支援有限 | 依赖 Pointer Events；Windows 触控板可用，平板手写笔已验证 |
| 上游升级需手动搬回 | 见第 2 节 |
